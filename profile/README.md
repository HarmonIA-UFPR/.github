# HarmonIA


# 📂 Repositórios

Este repositório pertence à organização **HarmonIA-UFPR** e reúne os projetos relacionados ao desenvolvimento do ecossistema HarmonIA.

Os diferentes repositórios da organização podem contemplar componentes como:

* portal web;
* assistente de IA;
* APIs e serviços;
* processamento e organização de dados;
* mecanismos de recuperação;
* avaliação e testes;
* infraestrutura;
* documentação;
* experimentos de pesquisa.

Cada repositório deve possuir seu próprio `README.md`, contendo informações específicas sobre instalação, arquitetura, desenvolvimento, execução e contribuição.

---

# 🔬 Pesquisa e desenvolvimento

O HarmonIA possui caráter **acadêmico e tecnológico**, articulando pesquisa, desenvolvimento de software, organização de dados e experimentação com Inteligência Artificial.

As atividades podem envolver:

* recuperação de informação;
* sistemas de recomendação;
* processamento de linguagem natural;
* modelos de linguagem;
* bancos de dados;
* busca vetorial;
* RAG;
* avaliação de sistemas de IA;
* análise de dados;
* curadoria de informação;
* interação humano-computador.

O projeto busca aproximar **pesquisa acadêmica e desenvolvimento tecnológico**, transformando resultados de pesquisa em componentes e funcionalidades aplicáveis ao ecossistema HarmonIA.

---

# 🌱 Princípios de desenvolvimento

O desenvolvimento do HarmonIA busca observar os seguintes princípios:

* **Abertura** — priorização de tecnologias, padrões e práticas abertas quando apropriado;
* **Reprodutibilidade** — documentação de procedimentos e experimentos;
* **Qualidade** — desenvolvimento orientado por testes, avaliação e melhoria contínua;
* **Transparência** — explicitação de critérios de curadoria e recomendação;
* **Privacidade** — tratamento responsável dos dados;
* **Interoperabilidade** — utilização de padrões e interfaces que favoreçam integração;
* **Sustentabilidade** — busca por soluções tecnicamente viáveis e eficientes.

# 🤝 Contribuição

As contribuições para os projetos da organização devem seguir as orientações específicas de cada repositório.

De forma geral:

1. Consulte o `README.md` do projeto;
2. Verifique as issues e discussões existentes;
3. Crie uma branch para sua contribuição;
4. Implemente e documente as alterações;
5. Execute os testes disponíveis;
6. Abra um Pull Request descrevendo as alterações realizadas.
